# 떡상 레이더 (Shortform Radar)

인스타 릴스 · 유튜브 쇼츠 · 틱톡의 **떡상 영상을 "채널 평균 대비 몇 배"로 찾아내는** 숏폼 수집기 & 벤치마킹 보드.
서버·빌드·외부 트래커 없이 정적 파일만으로 동작하고, 모든 데이터는 브라우저 `localStorage`에만 저장됩니다.

- 벤치마킹·설계 근거: [`../../reports/shortform-radar-benchmark.md`](../../reports/shortform-radar-benchmark.md)
- 미리보기: `preview-desktop.png` (1440×900), `preview-mobile.png` (390×844), `preview-modal.png` (상세 모달), `preview-live-yt.png` · `preview-live-yt-detail.png` (모의 API로 4건을 실제 수집한 상태 — 필터 바의 '실시간 수집만'과 상세 모달의 실제 썸네일 표시), `preview-upgraded.png` (AI 탭의 카피 심리학 + AI 브리지)

## 실행

```bash
# 가장 간단한 방법 — 폴더에서 정적 서버 실행
cd apps/shortform-radar
python3 -m http.server 8080
# → http://127.0.0.1:8080
```

`index.html`을 더블클릭해도 대부분 동작하지만, YouTube API는 `http(s)` 오리진에서만 호출되므로 로컬 서버 사용을 권장합니다.
배포는 GitHub Pages 같은 정적 호스팅에 이 폴더를 그대로 올리면 됩니다(빌드 없음).

### 실시간 수집만 보기

필터 바 오른쪽의 **실시간 수집만** 토글은 데모 28건을 빼고 **내가 모은 영상만** 남깁니다. 기준은 YouTube API 실시간 수집(`source: youtube-api`)과 링크·CSV로 직접 넣은 카드(`url`·`csv`)이며, 버튼 옆 숫자가 현재 내가 모은 개수입니다.

- YouTube API·링크·CSV로 **새 영상이 추가되면 자동으로 켜지고**(토스트로 안내) 데모는 숨겨집니다. 다시 끄면 데모까지 모두 보입니다.
- 켠 상태에서 모은 영상이 없으면 빈 화면에 이유를 안내합니다. `초기화`를 누르면 토글도 함께 꺼집니다.
- 모바일(≤620px)에서는 `초기화` 버튼 대신 이 토글이 자리를 지키고, 필터 줄은 가로로 스크롤됩니다.

## 떡상 점수 = 0~100

```
배수     42점  log10(조회수 ÷ 채널 기준) / log10(20)      ← 20x에서 만점
속도     28점  log10(1 + VPH) / log10(1 + 1,000,000)      ← 시간당 조회
반응     18점  (좋아요 + 댓글) ÷ 조회 ÷ 12%                ← 참여율 12%에서 만점
신선도   12점  6시간 이내 만점, 30일에서 0 (로그 감쇠)
```

- **VPH** = 조회수 ÷ 게시 후 경과시간(최소 0.25시간)
- **채널 기준 조회수**: 수집 표본이 3개 이상이면 그 채널 영상들의 **중앙값**, 아니면 채널 전체 평균(총 조회 ÷ 영상 수), 그것도 없으면 구독자 × 0.6 추정. 어떤 기준을 썼는지 상세 모달에 표시합니다.
- 점수는 UI에 요소별로 `36.5/42 · 28/28 · 5.8/18 · 9.9/12`처럼 그대로 노출됩니다(블랙박스 아님).

## 카피 심리학 — 8대 트리거 진단 (`engines/copy-psych-engine.js`)

카드를 열면 수집된 **제목·훅 문구·해시태그·CTA·상품명**을 8개 축으로 채점합니다.

| 축 | 보는 것 |
|---|---|
| 손실 회피 | 놓치면·그대로 두면·되돌릴 수 없음·낭비 |
| 구체적 숫자·앵커링 | 단위 숫자, 정가→판매가, 배수, 시간 약속 |
| 호기심 갭 | 질문, 왜, 아무도 모르는, 알고 보니 |
| 인지 반전 | ~하지 마세요, 반대로, 상식 깨기 |
| 사회적 증거 | 후기, N명 선택, 재구매, 평점 |
| 희소성·기한 | 한정, 선착순, 마감, 잔여 |
| 권위·실측 | 실측, 데이터, 인증, 출처, 직접 써봄 |
| 초저마찰 CTA | 클릭, 무료, 3초, 가입 없이 |

- 화면은 등급보다 **트리거 커버리지(8개 중 몇 개를 40점 이상으로 쓰는가)**를 앞세웁니다. 제목은 짧아 종합 등급이 낮게 나오는 게 정상이고, 영상 자체의 성과와도 별개입니다(화면에도 그렇게 적혀 있습니다).
- 빈틈 상위 3개는 바로 고칠 수 있는 문장 예시로 보여줍니다.
- **내 버전 리라이팅**: 내 제품·타깃(그리고 접어둔 문제·해결·근거·CTA)을 넣으면 PAS·BAB·AIDA·4U 네 가지로 다시 씁니다. 초안 자체를 다시 진단해 `레퍼런스 1/8 → 초안 3/8`처럼 비교합니다.
- 문제·해결은 카테고리별 기본 문장에서 출발하고, **근거 숫자는 비워 둡니다**. 레퍼런스 영상의 조회수를 내 실적처럼 옮겨 쓰지 않기 위해서입니다. 내 수치를 넣으면 권위·앵커 점수가 함께 오릅니다.
- [이 문구 복사]로 그대로 가져갑니다.

## 내 구독 AI 원클릭 브리지 (`engines/ai-bridge.js`)

선택한 영상의 **제목·조회수·바이럴 배수·VPH·참여율·훅 분해·심리 진단**과 **내 제품·타깃**을 한 프롬프트로 묶어 세 곳으로 보냅니다.

- **[ChatGPT 열기] · [Claude 열기]** — `?q=`로 프롬프트가 입력창에 채워집니다(각 서비스가 공식 보장하는 기능은 아니므로, 채워지지 않으면 클립보드에서 붙여넣으면 됩니다).
- **[Gemini 열기]** — 주소 자동 입력이 안 되므로 프롬프트를 클립보드에 복사하고 창을 엽니다.
- **무료 Gemini API 키(선택)** — 키를 넣으면 앱 안에서 바로 30초 대본을 받습니다. 요청은 `generativelanguage.googleapis.com` 한 곳으로만 나가고, 키는 이 브라우저의 localStorage에만 남습니다.
- 받은 대본을 붙여넣으면 **비트(0~3초…)·글자수·CTA 유무**를 확인하고 **[내 대본으로 저장]**합니다. 저장한 대본은 그 영상에 남아 다시 열면 그대로 나옵니다. 보드에 저장한 카드라면 메모에 붙일 수도 있습니다.
- 프롬프트에는 “레퍼런스 수치를 내 실적처럼 쓰지 않는다”는 규칙이 들어갑니다. 없는 숫자를 만들지 않게 하기 위해서입니다.

## YouTube 실시간 수집 (BYOK, 무료)

1. [Google Cloud 콘솔](https://console.cloud.google.com/projectcreate)에서 프로젝트 생성
2. **YouTube Data API v3** 사용 설정
3. 사용자 인증 정보 → API 키 발급 → (권장) HTTP 리퍼러 제한에 배포 도메인 등록, YouTube Data API만 허용
4. 앱 우측 상단 **YouTube API** 버튼 → 키 저장

- 키는 **이 브라우저의 localStorage에만** 저장되고 서버로 전송되지 않습니다. 요청은 `googleapis.com`으로만 나갑니다.
- 호출: `search.list`(videoDuration=short, order=viewCount, regionCode=KR/US, publishedAfter) 1회 + `videos.list` 1회 + `channels.list` 1회.
- 2026년 6월부터 `search.list`는 **자체 할당량(기본 하루 100회, 1회 1유닛)**, 나머지는 기본 1만 유닛을 씁니다. 앱이 날짜별 호출 수를 세어 설정 화면에 `오늘 검색 3/100`으로 보여주며, 태평양시 자정에 초기화됩니다.
- 403(할당량 초과·API 미사용), 400(잘못된 키), 네트워크 오류를 각각 다른 문구로 안내합니다.
- 공용 PC에서는 키를 저장하지 마세요. `설정 → 내 데이터 초기화`로 키·수집 데이터를 한 번에 지울 수 있습니다.

## 링크 · CSV 수집

**링크 붙여넣기**: 한 줄에 하나. TikTok·YouTube는 oEmbed로 제목·작성자를 best-effort로 읽고, YouTube는 키가 있으면 지표까지 자동 수집합니다. 인스타·틱톡은 공개 API가 없어 조회수·좋아요를 직접 넣거나, 나중에 카드 상세의 **지표 입력** 폼으로 채우면 배수·VPH·점수가 계산됩니다.

**CSV**: 헤더 예시

```csv
url,platform,creator,views,likes,comments,avg_views,hours_ago,category,caption,hashtags
https://www.youtube.com/shorts/dQw4w9WgXcQ,youtube,@sample.creator,540000,29200,1180,200000,18,푸드·맛집,"냉동만두, 물 없이 굽는 법",#냉동만두 #자취요리
```

`조회수`·`좋아요` 같은 한글 헤더도 인식하고, `1.2만`·`54만`·`1.3M` 표기도 숫자로 변환합니다.

**보드 내보내기**: 상태·크리에이터·플랫폼·캡션·조회·배수·VPH·점수·태그·메모·링크가 담긴 CSV(UTF-8 BOM, 엑셀 호환)와 전체 JSON.

## 프라이버시

- 서버 없음, 계정 없음, 광고·분석 스크립트 0건, 쿠키 0건.
- 외부 요청은 **사용자가 직접 실행한 것뿐**입니다: YouTube API 호출, 붙여넣은 링크의 oEmbed 조회, AI 창 열기(새 창), Gemini 키를 넣고 [Gemini로 생성]을 눌렀을 때의 Gemini API 호출. 앱이 스스로 외부로 나가는 요청은 없습니다(데모 모드 네트워크 0건을 테스트로 확인).
- YouTube·Gemini 키는 이 브라우저의 localStorage에만 저장되고 어디로도 전송되지 않습니다. `설정 → 내 데이터 초기화`로 한 번에 지웁니다.
- 데모 데이터 28건의 수치·상품·GMV는 전부 시뮬레이션이며 화면에 그렇게 표시됩니다. 실제 크리에이터·브랜드의 성과로 오인되지 않도록 핸들도 가상입니다.

## 테스트

```bash
node test.js          # 코어·엔진 로직 단위 테스트 333개
python3 uitest.py     # 실제 Chrome 데스크톱(1440×900)·모바일(390×844) 검증 197개
```

- `test.js`는 `core.js`(DOM 없는 순수 로직) · `data.js` · `engines/copy-psych-engine.js`를 그대로 불러 검증합니다. Node가 없는 환경에서는 Playwright에 번들된 런타임으로도 실행됩니다:
  `/workspace/.local/lib/python3.12/site-packages/playwright/driver/node test.js`
- `uitest.py`는 폴더를 로컬 HTTP로 띄우고, 별도 프로필의 헤드리스 Chrome으로 다음을 확인합니다.
  콘솔 에러 0, 404·요청 실패 0, 가로 넘침 0, 필터·정렬·검색, **실시간 수집만 토글(수집 전 0건·수집 후 자동 전환·데모 왕복)**, 모달·훅 분해·클립보드, **상세 모달 썸네일 레이어링(커버 전체를 덮는지·SVG 위에 그려지는지 hit-test)**, 칸반 이동·드래그·메모·새로고침 유지·CSV/JSON 다운로드, 다크모드 유지,
  **카피 심리학(트리거 8개·커버리지·빈틈 3개·4개 프레임워크 전환·내 제품 반영·복사)**, **AI 브리지(3개 버튼·새 창 URL·프롬프트 클립보드·모의 Gemini 호출·대본 저장·복원·오류 처리)**, **모의 googleapis로 실제 수집 파라미터·배수 계산·할당량 미터·403/400 오류 처리**, URL/CSV 수집, 지표 미입력 카드 보정, 모바일 레이아웃.
- 스크린샷은 `preview-desktop.png` · `preview-mobile.png` · `preview-modal.png` · `preview-live-yt.png` · `preview-live-yt-detail.png` · `preview-upgraded.png`로 저장됩니다. 실시간 스크린샷은 모의 googleapis·i.ytimg.com 응답(PIL로 그린 'MOCK THUMBNAIL' 이미지)으로 실제 수집 흐름을 돌려 찍습니다.
- 이 실행 환경은 프로세스·스레드 한도가 빠듯해 Chrome 기동이 zygote/pthread 단계에서 죽는 일이 있습니다. `uitest.py`는 `--no-sandbox` + 재시도(일반 모드 3회 → 단일 프로세스 모드 3회)로 버팁니다.

| 보더 | 1px `#E7E8EA` (hover `#D7D9DD`) | 모든 표면 경계. 그림자 대신 헤어라인 |
| 라운드 | 16px (`--r-lg`), 입력·칩 10~12px | 카드·패널·모달·스탯 타일 |
| 잉크 | `#0C0D0F` / `#3C4045` / `#4A4F55` / `#6B7076` | 제목·본문·보조·라벨 |
| 액센트 | 코발트 `#2F5BFF` 하나 | 주 버튼·활성 필·점수·막대·링크 |
| 헤드라인 | IBM Plex Sans KR 800, 자간 -0.04em | `h1`·스탯 숫자·패널 제목 |

- 대비는 라이트·다크 모두 실측 4.5:1 이상입니다(최저: 라이트 라벨 `#6B7076` on `#FAFAFA` 4.79:1, 액센트 `#2F5BFF` on `#FAFAFA` 4.95:1).
- 상태색은 의미가 있을 때만 씁니다: 완료 `#0E9F6E`, 오류 `#C02626`, 경고 `#B4441A`. 장식용 두 번째 액센트는 두지 않았습니다(칸반 상태 점은 회색→코발트 램프 + 완료 초록).
- 다크 테마는 같은 규칙의 잉크 캔버스입니다: 배경 `#08090B`, 표면 `#121316`, 보더 `#26282E`, 액센트 `#7C97FF`(위에 오는 글자는 잉크색).
- 카드 hover는 2px 부상 + `0 12px 28px -20px` 그림자 1단계만, `prefers-reduced-motion`에서 모션을 끕니다.

## 알려진 한계

- 8대 트리거 진단은 **수집된 제목·훅·해시태그·CTA만** 봅니다. 영상 본문(자막·음성)은 수집하지 않으므로 “영상이 왜 터졌는지” 전체를 설명하지는 않습니다. 제목이 짧아 종합 등급이 D로 나오는 일이 흔하고, 그래서 화면은 커버리지를 앞세웁니다.
- 리라이팅의 문제·해결 문장은 카테고리별 **초안**입니다. 내 상황에 맞게 고쳐 쓰는 것이 전제이고, 근거 숫자는 사용자가 넣어야 합니다.
- ChatGPT·Claude의 `?q=` 자동 입력은 각 서비스가 공식 문서로 보장하지 않는 기능입니다. 막히면 클립보드 붙여넣기로 끝납니다.
- Gemini 모델 이름은 서비스 사정으로 바뀔 수 있습니다. 400·404가 나면 모델을 바꿔 보세요.
- 인스타그램 릴스·틱톡은 공식 공개 통계 API가 없습니다. 링크·CSV로 넣고 지표를 직접 채우는 방식이며, 이는 의도된 설계입니다(크롤링·약관 위반 회피).
- YouTube API 모드의 채널 기준값은 "이번 검색에서 모인 같은 채널 영상의 중앙값"입니다. 채널 전체 이력을 다 받아오는 유료 툴과 완전히 같지는 않으며, 상세 모달에 기준 방식을 표기합니다.
- 커머스 탭의 GMV·상품은 데모 시뮬레이션입니다. 실제 커머스 데이터는 상품 링크/가격을 직접 넣는 방식으로 확장할 수 있습니다.
- 데이터는 브라우저에만 있으므로 브라우저 데이터를 지우면 사라집니다. `설정 → 전체 백업(JSON)`으로 보관하세요.
- 데모 카드의 커버는 외부 이미지가 아닌 SVG 생성 이미지입니다(깨짐·저작권·외부 의존 0). 실제 수집 영상은 YouTube 썸네일을 사용합니다.
